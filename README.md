# Lightmeter

Implementing a lightmeter using an Arduino, with aperture and shutter speed priority modes.
Built during [Adimian](https://adimian.com/) R&D week 2024.

## Components

- Adafruit Trinket M0
- SSD1306 OLED display
- Adafruit VEML7700 light sensor
- 2x push buttons
